# 💬 ChatMT

ChatMT — это мощное и легкое решение для управления чатом на серверах Minecraft (Paper/Spigot 1.16+). Плагин объединяет в себе форматирование, защиту и инструменты модерации.

## ✨ Основные функции
* HEX & Gradients: Полная поддержка современных цветов &#FFFFFF.
* Mentions: Звуковые и визуальные уведомления при упоминании игрока.
* Smart Censorship: Система анти-мата с настраиваемыми наказаниями.
* Command Control: Гибкие Белые/Черные списки команд.
* Persistent Data: Муты сохраняются в data.yml и не пропадают после рестарта.
* Multi-lang: Полная поддержка русского и английского языков.

## 🛠 Команды и Права
| Команда | Описание | Право |
| :--- | :--- | :--- |
| /chatmt reload | Перезагрузка конфига и языков | chatmt.admin |
| /mtmute <player> | Выдать/снять мут | chatmt.staff |
| /mtkick <player> [r] | Кикнуть игрока | chatmt.staff |
| /mtban <player> [r] | Забанить игрока | chatmt.staff |

Дополнительные права:
* chatmt.color — доступ к использованию цветов в чате.

## 📦 Интеграции
Плагин автоматически поддерживает:
* Vault & LuckPerms (через PlaceholderAPI)
* PlaceholderAPI (для плейсхолдеров в чате)
* WorldEdit & WorldGuard
* EssentialsX
* ItemsAdder / Oraxen
* MythicMobs

## 🚀 Установка
1. Скачайте последнюю версию .jar.
2. Поместите в папку /plugins/.
3. Установите PlaceholderAPI для работы префиксов.
4. Перезапустите сервер.
